# 📋 Доска практики

Android-приложение на Kotlin, которое каждый день выдаёт задания для практики в трёх сферах:

| Раздел | Что внутри |
|---|---|
| 💻 **Программирование** | 64 задания: основы, строки, коллекции, алгоритмы, ООП, корутины, Android, мини-проекты |
| 🧊 **3D-моделирование** | 58 заданий: интерфейс, low-poly, hard-surface, скульптинг, UV, материалы, свет, анимация, Geometry Nodes, риггинг |
| 🎨 **2D-арт** | 58 заданий: линии, перспектива, свет и тень, цвет, анатомия, портрет, жесты, композиция, дизайн персонажа |

## Возможности

- **Доски по дням.** Каждый день — своя доска с новыми заданиями. Можно листать 13 дней назад и 2 дня вперёд, отмечать выполненное, обновлять и добавлять задания.
- **Виджет на главный экран** в виде той же доски: стрелки ◀ ▶ листают дни, нажатие на задание отмечает его выполненным, «↗» открывает приложение на этом дне. В полночь виджет сам переключается на новую доску.
- **Настройки:** сколько заданий каждой сферы в день (0–5) и какая сложность — новичок, средний, продвинутый, смешанная или «по дням недели» (Пн–Вт легко, Ср–Пт средне, выходные — большие задания).
- **Процедурный генератор** (без интернета): собирает задания из тысяч комбинаций (объект × стиль × ограничение × настроение). Долю генератора на доске можно настроить.
- **ИИ-наставник (Claude, по желанию):** пишешь тему («хочу потренировать руки», «корутины») — ИИ придумывает задания под твой уровень. Нужен свой API-ключ Anthropic (console.anthropic.com); запросы платные по тарифам Anthropic. Ключ хранится только на телефоне.
- **Раздел «Обучение»** в каждой сфере: дорожная карта тем от новичка до продвинутого (что изучить, как практиковаться, ссылка на задания по теме), пошаговый план «Как учиться», полезные ресурсы и общие принципы.
- **Статистика:** серия дней подряд, сколько выполнено, сколько активных дней.
- **«Мои задания»:** удачные задания от генератора и ИИ сохраняются и пополняют базу.

## Установка

1. Скачай `PracticeBoard.apk` из раздела **Releases** этого репозитория (или из папки `apk/`).
2. Открой файл на телефоне и разреши установку из неизвестных источников.
3. Добавь виджет: долгое нажатие на главном экране → «Виджеты» → «Доска практики».

Требуется Android 8.0 и новее.

## Сборка из исходников

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17 и Android SDK (compileSdk 35). Каждый push собирает APK через GitHub Actions (`.github/workflows/build-apk.yml`) и публикует его в Releases.

> Ключ подписи `app/practiceboard.keystore` лежит в репозитории, чтобы новые версии ставились поверх старых. Если будешь публиковать приложение в магазине, сгенерируй собственный ключ.

## Структура кода

```
app/src/main/java/com/practiceboard/app/
├── MainActivity.kt          — точка входа
├── data/
│   ├── Models.kt            — сферы, сложность, задания, доски, настройки
│   ├── ProgrammingTasks.kt  — база заданий по программированию
│   ├── ModelingTasks.kt     — база заданий по 3D
│   ├── ArtTasks.kt          — база заданий по 2D
│   ├── TaskGenerator.kt     — процедурный генератор заданий
│   ├── BoardBuilder.kt      — сборка доски на день по настройкам
│   ├── Learning.kt          — темы обучения и советы «как учиться»
│   └── Repository.kt        — хранение досок, настроек и прогресса
├── ai/ClaudeTaskGenerator.kt — генерация заданий через Claude (Anthropic Java SDK)
├── widget/                  — виджет-доска (AppWidgetProvider + RemoteViewsService)
└── ui/                      — экраны на Jetpack Compose
```
