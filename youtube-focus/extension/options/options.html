FocusTube

Оставляем на YouTube только научное, образовательное и творческое.

Фильтр

Время

Задержка нужна, чтобы «на минутку выключить» было не так просто: за 20 секунд обычно успеваешь передумать.

Мои интересы

По одному на строку. Появятся кнопками на главной и дают ролику +2 балла, если встречаются в названии.

Белый список каналов

Название канала или @handle, по одному на строку. Эти каналы показываются всегда.

Чёрный список каналов

Эти каналы скрываются всегда.

Разрешённые слова

+3 балла, если слово есть в названии.

Запрещённые слова

−5 баллов, если слово есть в названии.

Категории YouTube (необязательно)

Без ключа FocusTube смотрит на названия, каналы, а у открытого ролика — ещё и на категорию, теги и описание. С ключом YouTube Data API v3 категория и теги проверяются и у роликов в ленте — фильтр становится заметно точнее. Ключ бесплатный: Google Cloud Console → «APIs & Services» → включить «YouTube Data API v3» → «Credentials» → «Create API key». Ключ хранится только в вашем браузере.
