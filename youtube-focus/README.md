# 🎯 FocusTube — только полезный YouTube

Плагин для браузера на ПК и приложение для Android, которые прячут развлекательные ролики
и оставляют на YouTube научный, образовательный и творческий контент.

Идея простая: YouTube нужен для учёбы и хобби, а лента рекомендаций, Shorts и «ещё одно видео»
съедают вечер. FocusTube убирает всё, что не похоже на полезное, и добавляет немного «трения»,
чтобы фильтр нельзя было выключить за одну секунду.

## Что умеет

| | ПК (расширение) | Android (приложение) |
|---|:---:|:---:|
| Скрывает неполезные ролики в ленте, поиске, рекомендациях, на каналах | ✅ | ✅ |
| Проверяет открытый ролик и закрывает его заставкой с объяснением «почему» | ✅ | ✅ |
| Убирает ленту рекомендаций с главной (вместо неё — поиск и ваши интересы) | ✅ | ✅ |
| Убирает Shorts (ссылки на Shorts открываются как обычный ролик и проверяются) | ✅ | ✅ |
| Скрывает миксы, подсказки в конце видео, по желанию комментарии | ✅ | ✅ |
| Белый/чёрный список каналов, свои разрешённые и запрещённые слова | ✅ | ✅ |
| Дневной лимит времени и статистика за день | ✅ | ✅ |
| Задержка 20 с перед выключением фильтра, паузой или смягчением режима | ✅ | ✅ |
| Точная проверка по категориям YouTube (нужен бесплатный API-ключ) | ✅ | ✅ |

### Как фильтр решает, что ролик полезный

Каждый ролик получает баллы:

| Примета | Баллы |
|---|---|
| Канал в вашем белом / чёрном списке | показать / скрыть всегда |
| Известный научпоп-канал (Veritasium, Kurzgesagt, ПостНаука, Arzamas, 3Blue1Brown…) | +5 |
| Категория «Образование» или «Наука и техника» | +4 |
| Творческая категория (фильмы и анимация, музыка, хобби) — если творчество включено | +3 |
| Слова в названии: «лекция», «урок», «как работает», «физика», «python», «tutorial», «explained»… | +1…+3 за слово (не больше +6) |
| Творческие слова: «рисую», «акварель», «blender», «гитара», «своими руками»… | +2 за слово (не больше +4) |
| Ваши интересы / разрешённые слова | +2 / +3 |
| Категория «Развлечения», «Юмор», «Видеоигры», «Люди и блоги» | −2 |
| Слова «пранк», «челлендж», «реакция на», «мемы», «прохождение», «тикток», «влог»… | −1…−4 за слово |
| Много эмодзи, «!!!», КАПС в названии | −1 |

Ролик показывается, если набрал не меньше порога режима:

- **Строгий** (порог 4) — нужно явное подтверждение: категория, известный канал или несколько «умных» слов;
- **Сбалансированный** (порог 2, по умолчанию) — достаточно одной полезной приметы;
- **Мягкий** (порог −1) — показывается всё, кроме явного развлекалова.

Когда ролик закрыт заставкой, видно, за что он получил баллы. Если фильтр ошибся, можно в один
клик добавить канал в белый список (с 10-секундной задержкой) или в мягком/сбалансированном режиме
«посмотреть один раз».

> **Про точность.** Без API-ключа ролики в ленте оцениваются по названию и каналу. У открытого ролика
> FocusTube дополнительно читает категорию, теги и описание прямо со страницы. С бесплатным ключом
> YouTube Data API v3 категория и теги проверяются и у роликов в ленте. Квоты (10 000 единиц в день)
> хватает с запасом: один запрос проверяет 50 роликов.
>
> Как получить ключ: [Google Cloud Console](https://console.cloud.google.com/) → создать проект →
> «APIs & Services» → «Library» → включить **YouTube Data API v3** → «Credentials» → «Create credentials» →
> «API key». Ключ хранится только у вас (в браузере или на телефоне).

## 💻 Установка на ПК

Подходит для Chrome, Edge, Яндекс Браузера, Opera, Brave, Vivaldi и Firefox 121+.

1. Скачайте `FocusTube-extension.zip` из раздела **Releases** и распакуйте
   (или возьмите папку `youtube-focus/extension` из репозитория).
2. **Chrome / Edge / Яндекс / Opera:** откройте `chrome://extensions` (в Edge — `edge://extensions`),
   включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку `extension`.
3. **Firefox:** `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» →
   выберите `manifest.json`. (Временные дополнения удаляются после перезапуска — для постоянной
   установки расширение нужно подписать на addons.mozilla.org.)
4. Закрепите значок FocusTube на панели: в окошке видно время за сегодня, режим, пауза.
   На значке расширения показываются минуты, проведённые на YouTube сегодня.

## 📱 Установка на Android

Есть два варианта, можно выбрать любой.

### Вариант 1. Приложение FocusTube (APK)

1. Скачайте `FocusTube.apk` из раздела **Releases** на телефон и установите
   (разрешите установку из неизвестных источников). Нужен Android 8.0+.
2. Откройте FocusTube — это мобильный YouTube со встроенным фильтром.
   Настройки — кнопка «⚙ Настройки FocusTube» на главной или долгое нажатие на иконку приложения.
3. Чтобы не тянуло в обычный YouTube:
   - **Настройки телефона → Приложения → YouTube → Отключить** (официальное приложение предустановлено,
     но его можно отключить);
   - **Настройки → Приложения → Приложения по умолчанию → Открытие ссылок** — пусть ссылки на YouTube
     открывает FocusTube. Ещё можно «Поделиться» ссылкой на ролик из любого приложения → FocusTube.

Ограничения: вход в аккаунт Google внутри встроенного браузера Google часто блокирует, поэтому
приложение работает без входа — подписок и истории нет, зато и персональные рекомендации не затягивают.
Фоновое воспроизведение не поддерживается.

### Вариант 2. Firefox для Android + расширение

Firefox для Android поддерживает расширения (манифест уже содержит настройки для него).
Чтобы поставить FocusTube туда, расширение нужно подписать на addons.mozilla.org (бесплатно, можно
как «неопубликованное»), после этого его можно установить из файла. Тогда YouTube открывается в Firefox,
и вход в аккаунт работает.

### Почему не «настоящий форк» приложения YouTube

Официальное приложение YouTube закрытое: его исходников нет, и изменять его нельзя (модифицированные
клиенты нарушают условия YouTube). Поэтому FocusTube для Android — это свой клиент на основе
мобильного сайта m.youtube.com, в который встроен тот же фильтр, что и в расширении. Один и тот же
JS-код (`extension/src`) работает и на ПК, и на телефоне.

## Как это устроено

```
youtube-focus/
├── extension/                 — расширение для браузера (Manifest V3)
│   ├── manifest.json
│   ├── src/
│   │   ├── defaults.js        — настройки по умолчанию, категории YouTube
│   │   ├── classifier.js      — оценка ролика баллами (слова, каналы, категории)
│   │   ├── metadata.js        — категория/теги: со страницы ролика или через YouTube Data API
│   │   ├── content.js         — работа со страницей: скрытие карточек, заставка, главная, лимит
│   │   ├── content.css        — скрытие Shorts, комментариев, ленты
│   │   ├── platform-extension.js — хранилище и сеть для расширения
│   │   └── background.js      — статистика, запросы к API, значок
│   ├── popup/                 — окошко по клику на значок
│   ├── options/               — страница настроек (с проверкой «как оценится ролик»)
│   └── test/                  — тесты классификатора (node --test)
└── android/                   — Android-приложение (Kotlin)
    └── src/main/
        ├── assets/platform-android.js — хранилище для фильтра через JavascriptInterface
        └── java/com/focustube/app/
            ├── MainActivity.kt    — WebView с m.youtube.com, встраивание фильтра, полный экран
            ├── SettingsActivity.kt — настройки на Jetpack Compose
            ├── JsBridge.kt        — мост JS ↔ Kotlin
            └── Store.kt           — настройки и статистика в SharedPreferences
```

Android-модуль подключает `extension/src` как assets, поэтому правка фильтра сразу попадает в обе версии.

### Сборка и тесты

```bash
node --test youtube-focus/extension/test/*.test.js
```

```bash
./gradlew :focustube:assembleRelease
```

APK появится в `youtube-focus/android/build/outputs/apk/release/focustube-release.apk`.
GitHub Actions собирает оба APK и zip с расширением при каждом push и выкладывает их в Releases.

### Если YouTube поменял вёрстку

YouTube регулярно переименовывает элементы страницы. Если ролики перестали скрываться, нужно
обновить списки селекторов `TILE_SELECTOR`, `TITLE_SELECTORS` и `CHANNEL_SELECTORS` в
`extension/src/content.js` (посмотреть актуальные теги можно через «Просмотреть код» в браузере).
