# dialog-export

Плагин Claude Code: команда `/export-dialog` сохраняет диалог в файлы, которые открываются без Claude и без интернета.

## Форматы

| Формат | Что получится |
|---|---|
| `html` (по умолчанию) | Один самодостаточный файл: Markdown, формулы KaTeX (`$…$`, `$$…$$`, `\(…\)`, `\[…\]`, `\begin{align}`, химия `\ce{}`), подсветка кода, картинки, PDF-вложения со встроенным просмотром, файлы с кнопками «Копировать» и «Скачать», вызовы инструментов (свёрнуты), оглавление, светлая и тёмная тема, печать. Библиотеки и шрифты встроены в файл, интернет не нужен. |
| `md` | Markdown: формулы приведены к `$`/`$$` (Obsidian, Typora, VS Code, GitHub), картинки встроены как data-URI, файлы и инструменты лежат в `<details>`. |
| `json` | Структура диалога: сообщения, части, вложения в base64. |
| `pdf` | Печать HTML через Chrome, Chromium или Edge в headless-режиме, если браузер есть. Без браузера откройте HTML и нажмите «Печать / PDF». |
| `all` | Все форматы сразу. |

## Примеры

```
/export-dialog                       # HTML в ./claude-exports/
/export-dialog md pdf --out ~/Docs   # Markdown и PDF в ~/Docs
/export-dialog html --out chat.html  # в конкретный файл
/export-dialog --no-tools            # без вызовов инструментов
/export-dialog --thinking            # с блоками размышлений
/export-dialog --list                # сессии этого проекта
/export-dialog --session 1a2b3c4d    # другая сессия (достаточно начала id)
/export-dialog --all md              # все сессии проекта
```

Можно и просто попросить: «экспортируй диалог в PDF». Для этого есть инструмент `export_dialog`.

## Откуда берётся история

Источник — файл истории сессии (`~/.claude/projects/<проект>/<id>.jsonl`), поэтому в экспорт попадает вся переписка, даже после сжатия контекста, с датой и временем каждого сообщения. Если файл прочитать не удалось, экспортируется текущий контекст сессии, о чём файл предупреждает в начале. Служебные вставки (system-reminder, тексты скиллов) в экспорт не попадают.

Встроенные библиотеки: KaTeX 0.16.11, marked 12.0.2, highlight.js 11.9.0 (лицензии в `assets/THIRD_PARTY_LICENSES.txt`).
