# Масляная косынка на Unity

Версия «Масляной косынки» для Windows (.exe), собранная на Unity 2022.3. Повторяет HTML-версию из папки `kosynka/`: пасьянс «Косынка», качки на картах, настройка всей колоды и каждой карты отдельно.

Всё рисуется кодом: качков, масти, рубашки и стол рисует собственный векторный растеризатор (`Raster.cs`), интерфейс сделан на IMGUI. Сцен, префабов и ассетов нет, игра собирает себя сама при запуске.

## Как получить .exe

### Вариант 1. GitHub Actions собирает сам

Workflow `.github/workflows/build-kosynka-exe.yml` запускается при каждом пуше в `kosynka-unity/`. Готовая игра появляется в разделе **Releases** (`Kosynka-Windows.zip`) и в артефактах запуска.

Unity не даёт собирать без учётной записи, поэтому один раз нужно добавить три секрета: **Settings → Secrets and variables → Actions → New repository secret**.

| Секрет | Что положить |
|---|---|
| `UNITY_EMAIL` | почта учётной записи Unity |
| `UNITY_PASSWORD` | пароль от неё |
| `UNITY_LICENSE` | всё содержимое файла лицензии `Unity_lic.ulf` |

Где взять `Unity_lic.ulf`: установи Unity Hub, войди в учётную запись и активируй бесплатную лицензию Personal (Hub → Settings → Licenses → Add). Файл появится здесь:

- Windows: `C:\ProgramData\Unity\Unity_lic.ulf`
- macOS: `/Library/Application Support/Unity/Unity_lic.ulf`
- Linux: `~/.local/share/unity3d/Unity/Unity_lic.ulf`

Открой его блокнотом и скопируй текст целиком в секрет `UNITY_LICENSE`. Без секретов workflow не падает, а пропускает сборку с предупреждением.

Перед сборкой workflow проверяет, что скрипты компилируются (`ci/compile-check.sh`). Для этой проверки не нужны ни Unity, ни лицензия: код собирается компилятором .NET против справочных сборок UnityEngine и UnityEditor с NuGet. Она ловит ошибки компиляции, но не проверяет, как игра работает. Запустить её у себя можно так: `kosynka-unity/ci/compile-check.sh` (нужен .NET SDK 8).

### Вариант 2. Собрать у себя

1. Установи Unity Hub и Unity **2022.3.76f1** (подойдёт любая 2022.3) с модулем **Windows Build Support (Mono)**.
2. В Hub нажми **Add → Add project from disk** и выбери папку `kosynka-unity`.
3. В меню редактора выбери **Kosynka → Собрать .exe для Windows** и укажи, куда сохранить.

Чтобы просто поиграть в редакторе, нажми **Play**: игра запускается в любой, даже пустой сцене.

## Свои картинки

Unity не умеет открывать окно выбора файлов, поэтому картинки берутся из папки **«Картинки»** рядом с `Kosynka.exe` (в редакторе — рядом с папкой `Assets`). Подходят PNG и JPG. Положи файлы, открой «Колоду» и нажми «Обновить» на вкладке «Картинки». Кнопка «Открыть папку» откроет её в проводнике.

Настройки оформления сохраняются в `%USERPROFILE%\AppData\LocalLow\Kosynka\Масляная косынка\kosynka-skin.json`.

## Управление

- Клик по карте отправляет её на лучшее место, карты и стопки можно перетаскивать.
- Клик по колоде открывает карту, по пустому месту колоды переворачивает сброс обратно.
- Ctrl+Z отменяет ход, F11 включает и выключает полный экран.
- Долгое нажатие или правый клик по открытой карте открывает её настройки.

## Код

```
Assets/Kosynka/
├── Scripts/
│   ├── KosynkaGame.cs        — запуск, партия, раскладка, анимация
│   ├── KosynkaGame.Gui.cs    — стол, карты, верхняя панель, победа, ввод
│   ├── KosynkaGame.Panel.cs  — панель «Колода» и редактор отдельной карты
│   ├── Klondike.cs           — правила и отмена ходов
│   ├── Art.cs                — рисунки карт, рубашки, стола, качков
│   ├── Raster.cs             — растеризатор: SVG-пути, эллипсы, сглаживание
│   ├── ImgLib.cs             — загрузка картинок игрока
│   └── Model.cs              — настройки колоды и карт, сохранение
└── Editor/BuildScript.cs     — сборка .exe (меню и CI)
```
